# 欢迎来到洛谷保存站帮助中心

洛谷保存站（Luogu Saver，简称 LGS）用于归档、检索和阅读来自洛谷的公开用户生成内容。它是非官方开源项目，与洛谷官方不存在隶属或背书关系。

本帮助中心同时面向普通访客、内容权利人、贡献者和自行部署者。文档基于保存站当前代码、`spec/` 规格、README、帮助中心历史和 Git 提交记录整理；涉及仍在变化的功能时，以保存站实际界面和主仓库 `master` 分支为准。

## 保存站能做什么

### 内容归档

当前公开保存工作流支持洛谷文章和剪贴板。访问尚未归档的合法内容 ID 时，保存站会提示创建保存任务；任务完成后，页面自动获取归档结果。文章保存还会串联历史版本、摘要、搜索索引等后续处理。

### 检索与阅读

保存站首页能识别洛谷链接、文章 ID、剪贴板 ID、用户 UID 和关键词。全文搜索支持关键词、作者 UID 与文章分类；文章页面还提供历史版本、评论、相关推荐、段落收藏和知识库入口。

### 发现与社区档案

文章广场会展示热门或基于匿名行为生成的推荐。陶片放逐模块归档社区权限变化记录，并提供同步日志与筛选能力。侧边栏的“犇犇保存站”是外部服务链接，不属于本仓库实现。

### 账号与治理

现役登录系统只使用 CP OAuth。登录后可提交内容移除申请、管理本地 RAG 知识库并接收审核通知。旧版剪贴板验证 Token 已退出登录链路，只作为历史资料保留。

## 文档中的状态标记

为避免把历史材料误当成现役说明，本文档采用以下表述：

- **现役**：与当前 `master` 代码和规格一致。
- **可选**：代码已支持，但依赖部署配置或外部服务。
- **仅管理员**：普通登录用户不可用。
- **历史资料**：用于解释旧链接、旧账号机制或项目演进，不应照做。
- **人工旧日志**：来自早期维护者手写更新日志，当前仓库无法逐条复核。
- **Git 可验证**：可由当前仓库的提交记录、文件或规格直接复核。

## 发现文档错误

文档与代码都在快速演进。发现过时说明时，可以直接使用页面底部的“在 GitHub 上编辑此页”，或在主仓库提交 issue。涉及安全漏洞、密钥或个人隐私时，请不要在公开 issue 中粘贴敏感内容。
