# 设置与本地数据

保存站的“设置”页同时管理账号状态、匿名推荐、本地阅读数据、RAG 知识库、导航偏好和连接信息。

## 账号

未登录时可以发起 CP OAuth 登录。登录后，设置页显示保存站本地用户 ID、绑定的洛谷 UID、名称、权限值和绑定时间，并提供刷新账号信息与退出登录。

退出登录会清除浏览器保存的登录 Token，但不会删除保存站服务器上的注册用户记录。

## 隐私与匿名推荐

“允许匿名数据追踪”控制浏览文章时是否发送匿名设备 ID：

- 开启：设备 ID 可用于记录近期文章行为和生成个性化推荐；
- 关闭：后续请求不发送设备 ID，文章广场使用公共推荐；
- 重置设备 ID：旧 ID 不再由当前浏览器继续使用，并在需要时生成新 ID。

该设备 ID 不是登录账号，也不应被当作稳定身份凭据。

## 本地数据

以下信息只保存在当前浏览器：

| 数据 | 用途 | 清理影响 |
| --- | --- | --- |
| 保存缓存 | 记录内容自动更新与保存相关时间戳 | 可能重新触发检查，不删除服务器归档 |
| 段落收藏 | 保存文章、剪贴板的标题段落收藏 | 收藏全部消失 |
| 陶片显示偏好 | 记录表格字段开关 | 恢复默认显示 |
| 登录 Token | 调用需要登录的接口 | 退出登录 |
| 主题与导航偏好 | 深浅模式、颜色、侧边栏行为 | 恢复默认外观与交互 |

## RAG 知识库

登录用户可以在文章页把文章加入知识库，最多 10 篇。知识库列表保存在浏览器本地，RAG 提问时可以选择“使用知识库强制召回”。

清空知识库不会删除文章归档，也不会改变其他用户的数据。

## 导航

“侧边栏 Logo 点击导航”开启后，点击 Logo 会返回首页。移动端侧边栏使用独立的展开与关闭交互。

## 连接信息

设置页显示：

- 当前选择的洛谷源站地址，用于内容页“原站”按钮；
- 保存站 API 地址，默认是同域名下的 `/api`，也可在构建时通过 `VITE_API_URL` 指定。

切换洛谷源站只改变打开原始页面的域名，不会把保存站后端切换到另一个数据库。
