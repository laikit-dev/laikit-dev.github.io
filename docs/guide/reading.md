# 阅读文章与剪贴板

内容页不仅展示一次抓取结果，还提供原文入口、历史、推荐、评论和本地阅读工具。

## 文章页面

文章页通常包含：

- 标题、作者、分类、标签与更新时间；
- Markdown 渲染正文和自动目录；
- 返回、打开原站、复制源码、更新、加入知识库和申请删除；
- 相关推荐；
- 历史版本时间线；
- 已归档评论。

相关推荐会标注来源：标题相似或向量相似等。推荐只是发现入口，不代表内容准确或受到项目认可。

## 剪贴板页面

剪贴板页展示作者、更新时间和渲染正文，并提供打开原站、复制源码、更新和删除申请。剪贴板没有文章分类、摘要、相关推荐和文章版本时间线。

## 目录、聚焦视图与段落收藏

文章和剪贴板支持按标题层级生成目录。阅读工具允许切换内容显示方式，并对标题对应的段落进行收藏。

段落收藏保存在当前浏览器本地，不会同步到账号或服务器。清理浏览器数据、使用无痕窗口或在设置中“删除收藏”都会使它们消失。

## 复制源码

“复制源码”复制的是归档的原始 Markdown，而不是页面渲染后的 HTML。查看文章旧版本时，复制的是当前选中的历史版本源码。

## Markdown 兼容性

保存站有独立的 Markdown 渲染包，支持常见 Markdown、代码高亮、KaTeX 数学公式、任务列表、标题锚点，以及部分洛谷风格指令、表格合并标记和 Bilibili 媒体转换。

源站语法不规范或使用未支持指令时，渲染可能与洛谷不同。保存站会对部分未闭合公式和验证码图片作容错处理，但不会保证像素级一致。

## 历史版本

文章内容发生变化时，保存站可以保留历史版本。时间线中的版本按版本号排序；URL 可以携带 `version` 查询参数打开指定版本。

历史版本是保存站曾抓取到的快照，不等价于洛谷的编辑记录，也不保证覆盖原作者每一次短暂修改。

## 评论

文章评论以只读方式归档。评论存在抓取时间和缓存周期，可能晚于洛谷当前状态；被软删除的文章不会向普通访客提供评论接口。

## 已删除内容

内容移除申请通过后，文章或剪贴板会被软删除：

- 普通访客只能看到“不可查看”和删除原因；
- 文章不再进入正常搜索与推荐流程；
- 具备内容管理权限的管理员可以查看归档正文并选择恢复；
- 文章历史、相关推荐和评论接口不会因管理员身份自动开放。

需要移除内容时，请阅读[数据移除政策](../license/deletion)，不要通过反复更新或制造无效保存任务代替正式申请。
