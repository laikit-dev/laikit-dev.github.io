# 常见问题

## 保存站是洛谷官网吗

不是。洛谷保存站是独立维护的非官方开源归档项目，与洛谷官方不存在隶属、授权或背书关系。归档内容的版权仍归原作者或权利人所有。

## 浏览或保存内容需要登录吗

浏览公开归档、搜索、查看文章广场，以及触发公开的文章/剪贴板保存工作流都不要求登录。RAG 问答、知识库和删除申请需要通过 CP OAuth 登录。

## 为什么旧文档要求申请 Token

那是已经退出使用的旧账号系统。当前登录系统只使用 CP OAuth；`/token/create` 已不再创建旧 Token。旧页面保留是为了说明历史链接和迁移背景，请不要再按旧步骤制作验证剪贴板。

## 归档内容会自动跟随洛谷更新吗

不保证。文章页可以在满足自动更新策略时检查更新，也可以手动点击“更新”；剪贴板也支持手动更新。源站删除、访问限制或网络异常会影响同步。

## 原文删除后，保存站为什么仍然存在

保存站的目标就是归档公开内容，因此源站删除不会自动等价于本站硬删除。权利人或相关用户可以登录后提交删除申请；管理员根据理由审核并通过站内通知反馈结果。

## 删除申请通过后是否彻底擦除数据库

现役自动审核流程执行的是软删除：普通访客不可查看，文章也不会出现在正常搜索结果中，但记录仍可用于审计和管理员恢复。确需硬删除的特殊请求需要额外联系运营者处理，且备份和日志可能存在合理的清理周期。

## 为什么看不到被删除内容

普通访客访问软删除内容会得到不可查看状态和删除原因。只有具备内容管理权限的管理员能够读取归档并执行恢复；相关推荐、历史和评论接口不会因为管理员身份而绕过删除限制。

## 推荐会跟踪我吗

默认取决于你在保存站中作出的匿名追踪选择。开启后，浏览器会发送一个匿名设备 ID，用于记录近期文章行为并生成推荐；关闭后，后续请求不发送设备 ID，广场使用公共推荐。可以在“设置”中关闭追踪或重置设备 ID。

## RAG 回答可靠吗

RAG 会从站内文章检索上下文，再由文本生成式 AI 生成答案。它可能遗漏材料、误解原文或生成错误结论。应打开回答下方的来源文章核对，不要把它当作事实、法律意见或竞赛判题依据。

## 为什么有些功能在侧边栏里没有

管理员入口和“用户文章爬取”等功能按权限显示；冬日绘板入口目前未作为现役保存站菜单开放；“犇犇保存站”会打开外部站点 `benben.sbs`。

## 保存失败如何排查

先查看工作流中的失败任务和错误原因。常见原因包括内容 ID 不存在、源站拒绝访问、网络或验证码挑战、队列拥堵、后端依赖不可用。仍无法判断时，附上内容类型、公开 ID、发生时间和错误文本提交 issue；不要附带敏感凭据。

## 如何报告安全问题或隐私问题

普通 Bug 可使用 [GitHub Issues](https://github.com/laikit-dev/luogu-saver/issues)。涉及 Token、Cookie、OAuth、个人信息或可利用漏洞时，不要公开完整细节，优先通过项目公开的私下联系方式或 QQ 群联系维护者。
