# 五分钟上手

这一页只介绍普通访客最常用的流程。浏览和保存公开内容不要求登录；提交删除申请、使用 RAG 问答和管理个人知识库时才需要登录。

## 1. 从首页输入内容

打开 <https://www.luogu.me>，在首页搜索框粘贴或输入以下任一种内容：

- 洛谷文章链接，例如 `https://www.luogu.com.cn/article/abcdefgh`
- 洛谷剪贴板链接，例如 `https://www.luogu.com.cn/paste/abcdefgh`
- 洛谷用户主页链接或纯数字 UID
- 八位文章 ID
- `article:abcdefgh`、`paste:abcdefgh` 或 `uid:123456`
- 任意搜索关键词

首页会优先识别明确的链接与 ID；无法识别为直接目标时，会进入全文搜索。

## 2. 打开已经归档的内容

如果内容已经存在，保存站会直接显示归档页面：

- 文章：标题、作者、分类、标签、正文、目录、历史版本、评论和相关推荐。
- 剪贴板：作者、正文、源码复制和显示模式。
- 用户：洛谷公开资料、认证等级、奖项和已保存的个人简介。

页面上的“原站”按钮会打开你在设置中选择的洛谷域名。

## 3. 保存尚未归档的内容

如果文章或剪贴板尚不存在，页面会提示保存。确认后，保存站创建一个公开工作流并显示任务状态。

1. 等待“保存”任务完成。
2. 页面会自动接收实时状态；断线后也可以重新打开工作流页面查看。
3. 成功后刷新或返回内容页。
4. 如果失败，先阅读具体原因，再决定是否重试。

::: warning 保存不等于绕过源站权限

保存站只能处理其抓取链路能够公开访问的内容。无效 ID、源站访问限制、验证码、网络异常或内容权限变化都可能导致保存失败。

:::

## 4. 更新已有归档

文章或剪贴板页面提供“更新”按钮。更新仍然通过保存工作流完成，不会直接覆盖页面：

- 内容没有变化时，后端可以跳过重复写入。
- 文章发生变化时，会保留历史版本，最新版与旧版本可在时间线中切换。
- 已软删除的内容不会向普通访客展示，也不会自动触发更新。

## 5. 登录使用个人功能

进入“设置”，点击“使用 CP OAuth 登录”。完成授权后会返回保存站。登录后可使用：

- 提交文章或剪贴板删除申请；
- 接收删除申请审核通知；
- 使用 RAG 问答；
- 把最多 10 篇文章加入本地知识库。

详情见[登录与账号](../account/login)。

## 6. 找不到内容怎么办

依次检查：

1. ID 是否完整，文章与剪贴板类型是否选对；
2. 原始洛谷链接是否仍能公开访问；
3. 页面是否显示明确的删除原因；
4. 保存工作流是否失败或仍在队列中；
5. [运行统计](../features/statistics)中的队列是否有堆积；
6. 是否可以通过[问题追踪](https://github.com/laikit-dev/luogu-saver/issues)确认已知故障。

不要在公开 issue 中粘贴登录 Token、Cookie、OAuth 回调参数或未公开内容。
