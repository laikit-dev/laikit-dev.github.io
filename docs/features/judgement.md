# 陶片放逐

“陶片放逐”归档洛谷社区用户权限变化记录。2026-07-19 起，该模块从独立旧服务整合进保存站后端和前端，使用统一数据库、队列、API 与部署流程。

## 可以查询什么

记录页支持组合筛选：

- 一个或多个用户 UID；
- 用户名模糊匹配；
- 被撤销的权限；
- 被增加的权限；
- 无权限变化的学术不端棕名记录。

所有已填写条件按 AND 组合。结果按事件时间倒序排列。

## 显示字段

可以在页面上控制是否显示：

- 名字颜色和头像；
- Badge、OI 认证与 XCPC 认证；
- UID、原因和时间。

字段显示偏好保存在浏览器本地，可在“设置”中删除并恢复默认值。

## 同步日志与统计

“同步日志与 API”入口展示抓取记录。公开只读 API 请查看[此处](https://www.luogu.me/judgement/logs)

## 数据来源与时效

同步任务从洛谷公开的 judgement 页面抓取数据。调度器在代码中默认关闭，生产环境是否启用、多久同步一次取决于部署配置；默认配置值是 20 分钟一次，但不能据此承诺线上实际频率。

同步失败会写入失败日志，不会伪造成功记录。页面中的用户快照与事件数据按抓取时状态保存，可能与当前洛谷用户资料不同。

## 使用边界

本页面是公开历史索引，不是洛谷官方处分通知。权限位含义、事件原因和用户信息应以洛谷官方页面为准；不要据此骚扰、挂人或推断未公开事实。
