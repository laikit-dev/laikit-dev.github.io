# 文章广场与推荐

文章广场用于发现已经归档的文章。它不是按更新时间简单排列的列表，而是结合热门程度、相似度和用户是否同意匿名追踪返回结果。

## 页面行为

- 首次进入时请求一批文章；
- 滚动接近页面底部时自动加载更多；
- 后续请求排除当前已经展示的文章，减少重复；
- 卡片显示标题、摘要、作者、分类和推荐原因；
- 点击卡片会在新标签页打开文章。

## 推荐来源

界面目前会标注两类主要原因：

- **热门**：依据公开热度和浏览指标返回；
- **猜你喜欢**：依据文章向量与匿名近期行为生成。

单篇文章下方的“相关推荐”还可能使用标题相似度或向量相似度。推荐原因只描述算法来源，不构成质量评价。

## 匿名追踪开关

只有在浏览器明确允许数据追踪时，请求才会携带匿名设备 ID。开启后，后端在 Redis 中保存有限数量的近期文章行为，并为数据设置过期时间；关闭后使用公共推荐，不读取或写入用户专属推荐键。

可以在“设置”中关闭追踪、复制或重置设备 ID。设备 ID 与 OAuth 登录用户不是同一个身份系统。

## 为什么推荐可能重复或不相关

- 新归档文章还没有摘要或向量；
- 向量服务被部署者关闭或暂时不可用；
- 匿名行为历史太少；
- 搜索索引、摘要或向量重建尚未完成；
- 热门内容池本身较小；
- 浏览器清除了设备 ID。

推荐系统是发现工具，不应被用于判断文章是否正确、原创或适合作为题解。
