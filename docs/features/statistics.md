# 运行统计

保存站“统计数据”页展示后端任务队列的实时运行状态，用于判断保存、抓取或 AI 工作流是否正在处理、排队或失败。

## 页面指标

- **WebSocket**：实时通道已连接、重连中或已断开；
- **等待任务**：waiting、paused、prioritized 和 waiting-children 的合计；
- **运行任务**：当前 active 任务；
- **失败任务**：BullMQ 当前保留的失败任务；
- **队列卡片**：并发数、等待、运行、延迟、依赖等待、优先等待、暂停、失败与完成数。

页面通过 WebSocket 自动接收更新，也可以手动刷新 HTTP 统计。

## 如何解读

- “有堆积”不一定是故障，可能只是任务量暂时超过并发；
- “暂停”表示队列或其中任务处于暂停状态；
- 失败数是队列保留值，不等于所有历史失败总数；
- WebSocket 断开只影响实时显示，不直接证明后端 worker 已停止；
- 完成数由 BullMQ 保留策略决定，不应当作永久业务统计。

## 它不是流量统计

运行统计面向队列健康，不统计访客、页面访问或来源。访问量见[流量分析](../special/analytics)；网站可用性则需要独立 HTTP 监控，不能仅靠“最近有没有 Umami 数据”判断。
